# 实现设计：只处理论文 PDF 的图内标签

状态：待实现；这份文档不是已验证的功能说明。

## 输入与输出

- 输入：论文 PDF、页码范围、翻译 API 配置、术语规则。
- 输出：保留原页尺寸的图内中文版 PDF、可选原文/译文双语 PDF、处理报告。
- 原 PDF 不覆盖。正文无需因此重新 OCR 或栅格化。
- 图片预览用于检查 PDF 中的图表，不将单独图片工具作为主产品。

## 路径选择

| 图表情况 | 处理方式 |
| --- | --- |
| 图内标签为 PDF 原生文字 | 获取文字、坐标、字号和方向，翻译后替换文字层 |
| 图内标签为图片像素 | 图表裁剪区域使用 RapidOCR，生成局部文字掩膜，修补后回填 |
| 原生文字、位图、矢量混合 | 两种结果按内容和位置去重，分别写回 |
| 提取内容与视觉不一致 | OCR 校验或保留原文并报告，不能仅信任文字层 |
| 无法可靠定位图表 | 让用户在论文预览上修正图框，再处理这个区域 |

**一张图能提取部分文字，不等于其他标签无需 OCR。**
不能以“这一页存在正文文字”或“图中至少有一个可提取标签”作为跳过 OCR 的条件。

## 图表定位

首选复用本地 PDFMathTranslate 的版面检测模型，获取完整 figure 区域。
不为此自动下载新的大型模型；若已有模型不可用，提供手工选择论文图框的路径。
单独的 PDF image 对象只用于辅助判断，不能当成完整图表区域。

图框需要保存页码、PDF 坐标、页面旋转与渲染比例。
裁剪区可按 200–300 DPI 渲染，映射时使用实际 pixmap 边界与尺寸，
处理裁剪取整、页面旋转、CropBox 和重复 image 对象。
识别与翻译以完整图的短标签为单位，避免按正文段落把不同模块标签串起来。

## OCR 与翻译

- OCR 使用已有 rapidocr-onnxruntime 1.4.4，CPU 执行，实例复用。
- 保存四点框、内容、置信度、来源和方向；低置信度结果可校正或跳过。
- 过滤纯数字与明显数学表达式；公式混排时保留对应片段，不能把所有英文大写词都视为缩写。
- 用户术语表可指定 CNN、ViT 等保留，以及 Encoder 等需要翻译的词。
- API 只接收文本及标签编号；无需把整篇论文或图像上传。
- 按图表批次翻译以保留上下文，严格校验标签数量与编号；失败不进入擦除阶段。
- 缓存键包含原文、服务地址、模型、目标语言、提示词与术语规则，不含 API 密钥。
- 超时、重试次数与取消均有上限；避免无限重试。

## 擦除与回填

原生文字路径使用文字定向删除，同时保留图像和矢量图形。
在临时页上先确认中文文本框可容纳，再提交替换，失败时保留原文。

位图路径需区分背景：

1. 纯色背景：估计局部背景，只填补文字掩膜。
2. 渐变或轻微纹理：尝试 OpenCV 局部修补，不下载模型。
3. 与箭头、坐标轴、曲线交叠：保留或进入人工检查，不能盲目涂白整个矩形。

掩膜应基于 OCR 框内的字形像素细化，检测长线与边框，限制外扩。
这个启发式是否有效仍待真实论文验证。
可优先叠加小范围修补图块和中文文字；如需要栅格化整个 figure 作为回退，
报告中明确标记该区域失去矢量可编辑性，并保留足够分辨率。

中文使用可嵌入字体，支持字号缩放、有限换行与旋转方向。
不同模块的文本框不能互相挤占；不擅自改变坐标轴数值、公式、图例颜色或箭头方向。
保存每个标签的原文、译文、框、回填字号、跳过原因和原始图表预览，方便复查。

## 开发顺序

1. PDF 图表清单与区域预览：先证明能正确找到完整图表，且正文不被当成标签。
2. 图内原生文字与轻量 OCR：验证混合图去重、方向、坐标映射和过滤规则。
3. API 翻译与术语校正：加入批次校验、缓存、失败处理。
4. 白底/纯色底局部回填及 PDF 输出：先做好最常见的流程图。
5. 复杂背景、预览修正、批量页码、进度取消和 Windows 启动界面。

每一阶段完成验证后单独提交 Git。先参考并核对来源，再引入许可明确的最小代码单元。
不直接复制其他项目的整个打包目录或所有模型。

## 验收标准

- 正文可选中的论文内，位图架构图中的自然语言标签被翻译。
- 矢量/位图/文字混合图不漏掉已嵌入像素的标签，也不重复翻译相同标签。
- 无标签照片、公式区域、数字刻度和指定缩写保持原样。
- 箭头、图框、曲线、颜色与图表布局可与原图对照。
- 中文无溢出、缺字或英文透底；不可靠替换有明确报告。
- 未选页、正文、原文件与双语输出中的原文页不变。
- 覆盖旋转页、裁剪页、重复图像、低置信度 OCR、API 超时、错误批次和取消。
- 真实 OCR 结果与合成测试都需验证；翻译 API 的在线效果单独记录。
