# 图内翻译实现

输入为论文 PDF，输出为中文版、原文与译文交替排列版及 JSON 报告；原文件不覆盖。

## 识别

复用已缓存 DocLayout ONNX 版面模型定位 figure。没有模型时辅助使用嵌入图片位置，也允许页面预览手动框选。已有模型不随仓库分发，不自动下载。

获取图内原生文字、位置、字号；同时运行 CPU RapidOCR，以覆盖原生文字和位图混合的图。重叠结果去重；乱码映射或与高置信度 OCR 明显冲突的原生文字使用 OCR 回退。旋转、低置信度标签标记供人工检查。

页面旋转和 CropBox 以统一的未旋转 PDF 坐标处理，导出保留页面属性。

## 翻译

API 接收原始标签、编号、图注、附近正文和可选用户背景。模型自己决定名称、缩写、单位等的处理，不使用本地术语保护或替换规则。纯数字、单字母标签不作为默认自然语言候选；界面允许检查结果。

严格检查返回编号、重复和缺失，错误批次不进入擦除。缓存包含服务、模型、提示词、上下文及原文；不包含密钥。请求有超时和有限重试，取消在请求返回后生效。

## 回填

默认保留原页面文字层与字体资源，使用局部不透明补丁遮盖英文并回填中文。这样避免重写已翻译正文或因透明图层改变原页面渲染。原英文仍在补丁下，译文附带搜索文字。原生文字定向删除保留为可选底层参数，默认不启用。

位图修补仅适用于可可靠估计的纯色背景：提取字形像素并有限扩张；边框、长线或复杂背景交叠时保留原文。复杂背景可选复用 Comic Translate 的 MI-GAN ONNX 接口；约 27 MB 的 CPU 模型不随仓库分发。字形掩膜直接复用上游组件过滤实现。不声称支持任意渐变或纹理背景。

中文可见字形改用 Comic Translate 的 PIL 字体度量及中文换行，输出局部透明字形图层并附隐藏文字以支持搜索；不分发系统字体。有限调整文本框高度及字号。先检查排版再擦除；不合适时保留原文并记录报告。页面原文件、未选页及双语版本中的原文页保留。

## 本地界面

Gradio 仅监听本机，提供页码、图框预览、可编辑识别表、上下文和 API 设置、取消、PDF 下载。密钥在内存中使用，界面不预填本地密钥。工作文件保存在 Git 忽略的 workspace。

API 总是接收图内所有标签的空间转录（包括非候选片段），用于区分代码区与自然语言。注释、文档字符串、函数和变量不得翻译；已中文内容保持原样。邻近标签先在同一背景上清理，再组合排版，避免局部补丁恢复旁边的原英文。
